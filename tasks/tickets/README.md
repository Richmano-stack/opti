# Primary Task Tickets

These tickets define the Opti MVP implementation sequence. Each ticket should be completed on its own short-lived branch and submitted as one PR against `staging`.

## Working agreement

1. Select the first unblocked ticket in `tasks/todo.md`.
2. Mark it active before implementation.
3. Implement only its stated scope.
4. Meet its acceptance criteria and the project-wide definition of done.
5. Mark it complete after the PR is merged.

If implementation changes an architectural or product decision, update `tasks/plan.md` and the affected ticket in the same PR.
