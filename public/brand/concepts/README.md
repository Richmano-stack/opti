# Opti logo concepts

1. **Focus Orbit** — movement from raw input to a more focused result.
2. **Refined Page** — the product's résumé/document function is most explicit.
3. **Open Horizon** — optimistic progress and forward opportunity.
4. **Precision Cut** — minimal, technical, and strongest at small sizes.

These are exploratory directions, not production-final assets. The selected direction should receive optical-spacing, monochrome, reversed, and favicon refinements.
